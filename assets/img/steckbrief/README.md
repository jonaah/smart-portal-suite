# Vorschaubilder der Steckbrief-Varianten

Dateiname `variante-<Nummer>.webp|png|jpg|svg` (z. B. `variante-2.png`).
Das Bild erscheint automatisch im Styling-Editor unter „Steckbrief-Variante“.
Empfohlen: erste Seite des PDFs, A4 hoch, ca. 420 × 594 px.
Alternativ in `config/report-variants.json` je Variante `"preview": "<Pfad oder URL>"` setzen.
